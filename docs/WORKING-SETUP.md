## Запуск

В корне выбранной рабочей копии:

```powershell
npm.cmd ci                     # один раз; собственные зависимости worktree
npm.cmd run dev:local -- --check # проверить зависимости и свободные порты
npm.cmd run dev:local           # API + Vite, Ctrl+C останавливает оба
```

Приложение: **http://127.0.0.1:5184/**.
Старый эксперимент AirBlock: **http://127.0.0.1:5184/?air2=1**.
Новый срез Calm с реальным каталогом: **http://127.0.0.1:5184/?calm=1**.
API: `127.0.0.1:4341`; Vite проксирует `/api` именно сюда.
Каталог — из существующего локального snapshot; аккаунт/журнал/cache пишутся
в `.tmp/dev-local` этой рабочей копии. AI, billing и тестовая авторизация
выключены. Ключи и production `.env` для этого запуска не нужны.
Vite обновляет UI на лету; после изменения API перезапустить команду.

Для второго одновременного dev-запуска задать другую пару портов:

```powershell
$env:RADIO_DEV_WEB_PORT = '5185'
$env:RADIO_DEV_API_PORT = '4342'
npm.cmd run dev:local
```

Прототип отдельно: `npm.cmd run dev:prototype` → http://127.0.0.1:4179.
Переносимый HTML: `npm.cmd run build:prototype` →
`docs/prototypes/calm/radioatlas-calm.html`. Это **макет без звука**, с четырьмя
фикстурами. Оформление прототипа не является интеграцией с Theme Studio.
Адреса loopback работают на этом компьютере, не на телефоне.

Новых платных интеграций и фоновых автоматизаций не установлено.

Node ≥24 выполнено. CI фиксирует Node 24.19.x: локальный прогон не заменяет
проверку CI того же коммита перед production. Системный Node не переустанавливали.

## Первый срез реализации

**Результат:** открыл приложение → включил эфир → сохранил понравившийся трек,
не покидая спокойную Главную. Работает реальный RadioContext и модель находок.

Входит:

- Композиция Главной из calm-прототипа с настоящим каталогом и локалями.
- Один компактный плеер, явная закладка трека; сердце станции — отдельное действие.
- Сохранение без перестройки страницы/смены станции и с неблокирующим подтверждением.
- Существующая навигация и доступ к расширенным действиям сохраняются.
- Реальные токены тёмной/светлой темы и пользовательское оформление из Theme Studio.
- Новая композиция за выключенным по умолчанию флагом; прежний путь сохраняется.

Не входит: новый ранжировщик, рекомендации по треку из жанров станции,
интеграция Лиры с находками, новый Глобус, запись эфира, новый аудиодвижок,
полный редизайн раскрытого плеера или расширение возможностей Theme Studio.

Приёмка: первый запуск и восстановление без ложного playing, запуск/пауза,
подключение/ошибка/нет metadata, поимка с прежним stationId и временем,
отсутствие сдвига Home/потери последней строки, ширины 320/390/411,
контраст и кликабельность при своей картинке. Мок не доказывает звук:
настоящий iPhone background-проверяется отдельно перед выкладкой.

### Реализация для просмотра

`CalmHome` получает существующую рекомендацию/станции Home и фиксирует их на
время посещения. `CalmMiniPlayer` использует тот же RadioContext, проверку
достоверности названия и `copyTrack`; отдельного аудиоплеера/хранилища нет.
Закладка исчезает без названия, при ошибке остаётся повтор. Полный плеер и
его дополнительные действия открываются нажатием на информацию в мини-плеере.
Поиск по настроению открывает существующий Search, «Подобрать другое» — Ленту;
переход сам по себе не переключает эфир. Находки открывают вкладку tracks.

`tests/calm-home.spec.ts` проверяет первый запуск, сохранение при отказе clipboard,
неподвижность разделов, размеры/доступность нижней строки на 320/390/411 в двух
темах, восстановление, подключение, ошибку/повтор, отсутствие metadata и собственную
картинку через настоящий редактор Theme Studio. Измерение ждёт шрифт и конечную
анимацию. Искусственные error/buffering изолируют сетевой WAV от медиа-мока:
иначе браузер способен сам послать playing, противореча имитируемому отказу.
Пробная правка useAudioPlayer по этому ложному сигналу удалена; аудиодвижок не менялся.

Остаётся дизайн-ревью владельца и проверка на настоящем телефоне перед выкладкой.
Шапка сохраняет существующие входы в настройки/аккаунт. Флаг выключен по умолчанию.

Проверки среза 10.09.2026: оба typecheck — exit 0; webapp unit — 834 passed;
полный функциональный Playwright — 299 passed, 7 штатных skip, exit 0 (6.7 мин).
В числе успешных — все 12 calm-сценариев. Мутация с удалённым вызовом copyTrack
дала ожидаемый красный результат, после чего обработчик восстановлен.
Кадры: `output/playwright/calm/real-{320,390,411}-{aurora-field,pastel}.png`
и `real-custom.png`; на них моковые станции/metadata/аудио, настоящие компоненты
и тема. Живой каталог отдельно открыт в dev-браузере по `?calm=1`.
Полную инвентаризацию проекта повторять не нужно.

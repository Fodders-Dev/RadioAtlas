**13.09 — фоновые команды наушников и восстановление транспорта.**
Media Session вызывает раздельные идемпотентные `resume` и `pause`.
При фоновом возобновлении приостановленного эфира переподключается та же
станция; возвращаться в приложение для выдачи recovery debt не требуется.
`current ?? pending` сохраняет системную карточку во время загрузки/ошибки.
При повторном Next отсчёт идёт от загружаемого/текущего источника, даже пока
очередь ещё хранит индекс последнего успешного воспроизведения.

У каждой незавершённой `play()` теперь один владелец, обработчик ошибки и
deadline 25s (время исполнения таймера зависит от фонового планировщика ОС).
Именно владелец продолжает варианты потока; watchdog завершает ожидание,
не создавая вторую гонку. Новая команда/пауза отменяет прежнюю попытку как
superseded; её поздний результат не ставит новую станцию на паузу и не снимает
защиту новой попытки. Play во время подключения не перезапускает её.
`audio.autoplay = false` заменяет ошибочное `autoplay="false"`, которое
браузер воспринимал как включённый автозапуск.

Проверено: обе проверки типов, 869 unit, сборка, 21 targeted Playwright
(наушники/свайпы/отсутствие самовольного переключения). Новый browser harness
вызывает настоящие обработчики Media Session из RadioContext, подменяя
транспорт и visibility; это не проверка физического телефона. Старый тест
буферизации теперь моделирует paused вместе с mocked play/pause: после удаления

## Первый срез реализации

**Результат:** открыл приложение → включил эфир → сохранил понравившийся трек,
не покидая спокойную Главную. Работает реальный RadioContext и модель находок.

Входит:

- Композиция Главной из calm-прототипа с настоящим каталогом и локалями.
- Один компактный плеер, явная закладка трека; сердце станции — отдельное действие.
- Сохранение без перестройки страницы/смены станции и с неблокирующим подтверждением.
- Существующая навигация и доступ к расширенным действиям сохраняются.
- Реальные токены тёмной/светлой темы и пользовательское оформление из Theme Studio.
- Новая композиция за выключенным по умолчанию флагом; прежний путь сохраняется.

Не входит: новый ранжировщик, рекомендации по треку из жанров станции,
интеграция Лиры с находками, новый Глобус, запись эфира, новый аудиодвижок,
новая архитектура аудиоплеера или расширение возможностей Theme Studio.

Приёмка: первый запуск и восстановление без ложного playing, запуск/пауза,
подключение/ошибка/нет metadata, поимка с прежним stationId и временем,
отсутствие сдвига Home/потери последней строки, ширины 320/390/411,
контраст и кликабельность при своей картинке. Мок не доказывает звук:
настоящий iPhone background-проверяется отдельно перед выкладкой.

### Реализация для просмотра

`CalmHome` получает существующую рекомендацию/станции Home и фиксирует их на
время посещения. `CalmMiniPlayer` использует тот же RadioContext, проверку
достоверности названия и `copyTrack`; отдельного аудиоплеера/хранилища нет.
Закладка исчезает без названия, при ошибке остаётся повтор. Нажатие на информацию
в мини-плеере открывает Ленту на текущей станции; дополнительные действия —
в её лотке «Ещё», таймер доступен также кнопкой в шапке Ленты.
Поиск по настроению открывает существующий Search, «Листать эфиры» — Ленту;
переход сам по себе не переключает эфир. Находки открывают вкладку tracks.

`tests/calm-home.spec.ts` проверяет первый запуск, сохранение при отказе clipboard,
неподвижность разделов, размеры/доступность нижней строки на 320/390/411 в двух
темах, восстановление, подключение, ошибку/повтор, отсутствие metadata и собственную
картинку через настоящий редактор Theme Studio. Измерение ждёт шрифт и конечную
анимацию. Искусственные error/buffering изолируют сетевой WAV от медиа-мока:
иначе браузер способен сам послать playing, противореча имитируемому отказу.
Пробная правка useAudioPlayer по этому ложному сигналу удалена; аудиодвижок не менялся.

Остаётся дизайн-ревью владельца и проверка на настоящем телефоне перед выкладкой.
Шапка сохраняет существующие входы в настройки/аккаунт. Флаг выключен по умолчанию.

### Текущий срез: Лента как раскрытый плеер

Владелец снова отклонил плоское оформление и предложил использовать свайповую
Ленту вместо отдельного полноэкранного плеера. В `?calm=1` вход из мини-плеера
и кнопки играющей рекомендации теперь ведёт в Ленту на выбранной станции.
Вход сохраняет поток; явный свайп использует прежний механизм переключения.
Мини-плеер в Ленте скрыт. Старый FullPlayer остаётся для других входов и пути
без флага; аудиодвижок не переписывался.

У карточки Ленты есть закладка достоверно известного трека. Кнопка «Ещё»
открывает `FeedPlayerTools`: действующий таймер 15/30/45/60 минут, отмена,
громкость, добавление в очередь, переходы к очереди/находкам, поделиться,
открыть поток, детали и скрытие станции. Таймер также доступен из шапки и
сохраняется при закрытии Ленты. В общем `sleepTimer.start` начальное remainingMs
задаётся сразу: больше нет промежуточного отображения 0:00. Лоток использует
существующий useDialog; клавиши громкости не передаются свайповому пейджеру.

На Главной усилены блики, цветные акценты, прозрачность и контактные тени.
Жанровые карточки предлагают конкретную станцию и дальнейший поиск. Направление
появляется по тегам реально загруженного каталога, повтор станции не допускается;
из пула убираются скрытые и известные как недоступные станции. Это не обещание
сходства с треком и не новый ранжировщик. На немоковом каталоге заметны слабые
метаданные (например, новостное название с тегом pop); качество отбора остаётся
ограничением и не подтверждается функциональными тестами.

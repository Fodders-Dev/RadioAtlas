## Открыть

Из `RadioAtlas-codex`, ветка `codex/calm-home`:

```powershell
node docs/prototypes/directions/serve.cjs
```

- Текущий просмотр: http://127.0.0.1:4180/
- Отдельный телефон: http://127.0.0.1:4180/journal.html?screen=home
- Другие входы: `screen=feed`, `screen=globe`, `screen=lira`.
- Предыдущий A2: http://127.0.0.1:4180/a2.html (`journal-a2.html` отдельно).
- Предыдущие А/Б: http://127.0.0.1:4180/comparison.html
- Прежние отдельные варианты: `concept.html?v=a` и `concept.html?v=b`.

Два телефона имеют одинаковый внутренний размер: 390×844, также 320 и 411.
Переключатель показывает пары Главная/Глобус и Лента/Лира. В каждом телефоне
есть собственная навигация и прокрутка. Поиск доступен в шапке Главной.

Нужны уже установленные зависимости проекта и существующий локальный API
на 5184 (`npm.cmd run dev:local`). Сервер слушает только loopback. В whitelist
прокси входят только GET каталога: search, points и stations/:id. Production,
AI, аккаунты и приватные endpoints не используются.

При старте `build-globe.cjs` собирает два виджета через установленный esbuild
в игнорируемую `.tmp/directions/`:
- `globe-entry.tsx` — прямой адаптер исходного `Globe.tsx` для сохранённого A2.
- `explorer-entry.ts` — отдельный слой взаимодействия MapLibre для A3:
  группировка, связанные списки, подсветка и поиск по области. Использует
  зависимости, Natural Earth и спутниковые тайлы Esri существующего приложения.

A3 не меняет и не заменяет production Globe. Оба виджета грузятся только
при открытии карты. Атрибуция Esri сохранена; подписи берутся из каталога.

## Изменения A3

- Главная: меньше обложка и отступы, сразу два эфира с Play, раньше видны
  тематические продолжения. Нижнее управление компактнее, основные цели 44 px.
- Карта: группы с количеством → приближение и названия в панели. Близкие и
  совпадающие точки доступны списком. Название фокусирует, Play включает;
  маленькую точку не обязательно ловить пальцем, доступна строка станции.
- Три размера панели: обычный, больше эфиров, больше карты. Поле поиска
  фильтрует показанные станции, остальные результаты загружаются в список по 20.
- Перемещение сохраняет список до «Искать здесь». После движения доступны
  соседи за границами выбранной страны. Количества вычисляются из реальных
  координат. Для фокуса страны используется медиана, сами маркеры не двигаются.
- Лира: компактнее приветствие, два настоящих источника с действиями сразу.
- Тёмная тема и уменьшение прозрачности учитывают новую панель. Существующие
  цветные и пользовательские фоны сохранены. Вертикальная Лента осталась A2.

## Сохранённые сценарии A2


- Главная сохраняет редакционный маршрут А: музыкальная история, источники,
  тематические продолжения, страны, жанры, личные находки и подборки.
  Обложка получила рельеф винила и свет, управление — цветные отражения и блики.
- Лента: одна станция занимает весь экран. Вертикальный свайп/drag вверх-вниз,
  колесо, стрелки клавиатуры и кнопки переключают эфир после фиксации страницы.
  Вход в Ленту сохраняет выбранную станцию и паузу. Отдельного большого плеера нет.
- Сердце принадлежит станции, закладка — примеру трека. Сохранение и таймер
  не пересоздают Ленту и не сбрасывают позицию. Таймер обозначается у кнопки.
  Громкость, очередь, источник и темы доступны в управлении эфиром.
- Страна → перелёт глобуса → светящиеся точки → карточка → отдельный Play.
  При фокусе показаны координаты выбранной страны, кнопка «Весь мир» открывает
  общий слой. Камера учитывает пространство над карточкой. Для фокуса страны
  используется медиана настоящих координат; сами точки не перемещаются.
  Станции без точных координат не получают выдуманный адрес/маркер.
- Лира: приветствие ведущей, поле ввода, история диалога, музыкальные предложения,
  карточки источников с Play и переходом на глобус, действие таймера из ответа.
  Запросы о джазе, таймере и помощи имеют готовые ответы. Произвольный запрос
  честно сообщает границу сценария и предлагает поиск по настоящему каталогу.
- Светлая, тёмная, Розовый кварц, Лагуна, свой градиент/картинка и уменьшение
  прозрачности сохранены. Сценический фон Ленты принадлежит станции.

На Главной сохранён небольшой снимок 12 настоящих станций из локального API.
Тематические подборки, жанры, поиск и список стран продолжаются через каталог
страницами по 20. Лента использует эти 12 источников и добавляет выбранный извне.
Карта получает публичные points по запросу; рисует только конечные lat/lon.
Наблюдение 11.09: 13 854 таких точек, Франция — 583, Япония — 12. Это результат
текущего каталога, не константы продукта и не доказательство точности всех данных.

Истории макета не выдаются за публикации сообщества. Публичная витрина пока
не реализована; выдуманных авторов и статистики нет. Лицо Лиры — собственный
векторный рисунок прототипа; присланное ранее изображение не используется.

# Два направления RadioAtlas — 11.09.2026

Стадия: интерактивные дизайн-макеты для выбора владельцем. Дизайн не принят,
в основное приложение ничего не перенесено. Не релиз и не аудиоинтеграция.

## Открыть

Из `RadioAtlas-codex`:

```powershell
node docs/prototypes/directions/serve.cjs
```

Сравнение: http://127.0.0.1:4180/

- А: http://127.0.0.1:4180/concept.html?v=a
- Б: http://127.0.0.1:4180/concept.html?v=b

Для продолжения подборок нужен существующий `npm.cmd run dev:local` на 5184.
Сервер макетов слушает только loopback; проксирует только GET
`/api/catalog/search` к этому локальному preview. Production не используется.
На Главной есть небольшой публичный снимок 12 реальных станций, полученный
11.09 через этот API. При недоступности каталога показаны ошибка и повтор;
список не подменяется фикстурами. Снимок не содержит потоков или аккаунтов.

Телефоны имеют одинаковый внутренний размер, по умолчанию **390×844**;
есть 320 и 411. Общий переключатель показывает Главные, Ленты, таймеры и
оформление одновременно. Содержимое каждого телефона прокручивается отдельно.

## Разница композиций

**А · Журнал:** тематическая музыкальная обложка → небольшая стартовая
выборка → истории с продолжением → страны → независимые источники → жанры.
Лира — знакомый проводник рядом с быстрым «Включай». В Ленте — крупная
музыкальная обложка, отдельно источник с сердцем и находка с закладкой.
Навигация: Главная / Поиск / Лента / Моё.

**Б · Атлас:** географический холст → страна → последовательность местных
эфиров → пересечение страны с жанром → маршрут без границ. Точки карты
открывают соответствующую страну, а не запускают музыку. Лента продолжает
пространство Атласа: географическая сцена и крупная типографика трека.
Навигация: Атлас / Лента / Поиск / Моё.

Карточки историй — авторская организация материалов макета, не публикации
сообщества. Авторы, слушатели, рейтинги и публикации не выдуманы. Публичная
витрина честно обозначена как будущая; личную подборку можно создать локально
из текущих любимых источников. Подборка фиксирует выбранные источники.
Векторное лицо Лиры нарисовано для этого макета; прежняя картинка не использована.

## Что интерактивно

- Выбор эфира, Play/Pause и намеренный горизонтальный свайп; кнопки и стрелки
  клавиатуры дублируют жест. Лента — единственная раскрытая поверхность плеера.
- Живое продолжение тематических подборок, стран, жанров и поиска страницами
  по 20. Исследование не меняет выбранный эфир.
- Сердце сохраняет станцию; закладка сохраняет пример находки без перестройки
  экрана. Находка содержит источник и время, открывается в поиске музыкального
  сервиса. Отказ clipboard не удаляет находку.
- Таймер с пресетами и своим временем, громкость, очередь, сведения об источнике.
- Светлая, тёмная и две цветные темы; редактор своего градиента и картинки,
  уменьшение прозрачности. Это работающий редактор **макета**, не интеграция
  с Theme Studio основного приложения.
- Контекст страны и прокрутки сохраняется при возврате из Ленты. Ранее открытый
  список не заменяется загрузочной заглушкой, чтобы не сдвигать прокрутку.
- Диалоги закрываются Escape и возвращают фокус. Повторный тап активной вкладки
  возвращает её содержимое наверх.

## Граница прототипа

**Аудио не подключено.** Состояния прослушивания моделируются. Khruangbin —
Friday Morning — явно подписанный пример для проверки находки, не заявление
о текущем треке станции. Истечение таймера меняет состояние макета; слайдер
громкости управляет только его моделью. AI и аккаунт не подключены, Лира
показывает готовые направления. Состояние личных действий живёт до перезагрузки
страницы. Это намеренная граница этапа выбора, а не обещание работающего релиза.

Географическая сцена декоративно обобщает карту мира, не заменяет существующий
интерактивный Глобус приложения. Свободный поиск и весь каталог доступны.

## Дизайн-основание

Изучены официальные Apple HIG:

- [Layout](https://developer.apple.com/design/human-interface-guidelines/layout)
- [Materials](https://developer.apple.com/design/human-interface-guidelines/materials)
- [Tab bars](https://developer.apple.com/design/human-interface-guidelines/tab-bars)
- [Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons)

Применение: выразительное основное действие, стабильные разделы, раздельные
слои содержимого и управления, раскрытие подробностей по запросу. Стекло
сосредоточено в плавающих элементах управления: реальный backdrop blur,
цветные отражения, тонкая светлая кромка. Не все строки и обложки стали стеклом.
Это CSS-материал, не нативный Liquid Glass.

- Настоящий pointer drag в Ленте: FIP → TSF Jazz. Отдельно кнопка следующего эфира.
- Сердце FIP и закладка дают одну станцию и одну находку в разных разделах «Моё».
- Таймер 30 минут, цветная и тёмная темы, свой градиент, выбор локального
  изображения через настоящий file chooser и выключатель прозрачности.

# Discovery next — проверка сценария Главной

Статус: предложение для обсуждения, не принятый дизайн и не рабочая сборка RadioAtlas.
Обоснование и инструкция для следующего прохода: [новое направление](../../DISCOVERY-DIRECTION-2026-09-13.md).

## Запуск

Из корня checkout:

```powershell
node docs/prototypes/discovery-next/serve.cjs
```

Открыть http://127.0.0.1:4192/. Сервер слушает только loopback, отдаёт явный набор
файлов и существующие локальные шрифты/иллюстрацию Лиры. Сборка и установка пакетов
не требуются. Остановка — Ctrl+C в процессе сервера.

## Что сравниваем

- Один прямой старт прослушивания рядом с конкретным приглашением исследовать.
- Просмотр маршрута отдельно от принятия новой очереди.
- Продолжение маршрута кнопкой Next, сохранение и возвращение через «Моё».
- Короткий вертикальный dock против верхней группы (переключатель в полосе концепта).
- Ситуативные входы к Лире вместо необходимости сначала придумать запрос.

Навигация сокращена до поверхностей этого эксперимента. Глобус и полноценная
Лента не заменяются и не удаляются из продуктового направления.

## Ограничения

Нет звука, AI, карты, запросов к API, облачного сохранения и изменения пользовательских
данных. Названия/теги взяты из публичного соседнего `directions/stations.json`.
Маршруты и ответы Лиры заданы вручную, сходство текущих треков не проверялось.
Сохранённое живёт в памяти страницы до её перезагрузки. Начало с FIP — демонстрация;
рабочий продукт должен учитывать реальную станцию и очередь вернувшегося слушателя.
Только светлая тема. Иллюстрации, типографика и плотность — первый вариант,
не завершённая художественная версия приложения.

## Проверено 2026-09-13

Ручной проход через инструменты браузера в Chromium, без физических устройств:

- 390×844: после уменьшения повторяющейся шапки Play и вход в маршрут видны
  на первом экране; нижний nav отделён от мини-плеера.
- 320×568: первый вариант прятал вход в исследование ниже nav. Добавлена компактная
  композиция для короткого окна; повторный снимок показывает обе кнопки выше nav.
  Диалог маршрута прокручивается; узкие строки станций исправлены и просмотрены повторно.
- 834×1112: просмотрены Главная, короткий dock, карточки и открытый мини-плеер.
- 1440×900: просмотрены боковой и верхний варианты. В верхнем варианте измерены
  заголовок и nav: пересечения и горизонтального overflow нет.
- Play FIP → открытие маршрута: текущая станция остаётся FIP. Сохранение маршрута →
  принятие маршрута → Next: текущий Worldwide FM, сохранённый маршрут доступен в «Моё».
- Фильтр «Спокойнее»: остаётся один соответствующий маршрут.
- Лира → «Спокойнее, но с характером»: открывается предложение Swiss Jazz →
  Groove Salad → FIP, без автоматического выбора эфира.
- На последнем проходе журнал браузера не содержал warning/error.
- Синтаксис JS/сервера проверяется `node --check`; пробельные ошибки — `git diff --check`.

Это проверка реализованных переходов и размеров, не доказательство удобства
для реальных людей. Полный unit/Playwright приложения к отдельному статическому
концепту не применялся. Реальный звук, тема Classic, экранная клавиатура,
assistive technology и работа на физическом телефоне этим проходом не проверены.

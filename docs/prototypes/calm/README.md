# RadioAtlas / calm — точка продолжения, 08.09.2026

Отдельный интерактивный прототип следующей итерации после обсуждения макетов Claude.
Его файл `radioatlas-calm.html` был виден только на скриншоте: локально исходник
не найден, опубликованный предыдущий артефакт не загрузился. Этот срез собран
заново по кадрам и согласованному поведению. Изменения приложения другого агента
не затрагивались. Ничего не коммитили и не деплоили.

## Запуск

Самодостаточный `radioatlas-calm.html` можно открыть прямо в браузере или передать
Claude целиком. Все стили, код и четыре SVG-иллюстрации внутри.

Для разработки из корня репозитория:

```powershell
node docs/prototypes/calm/serve.cjs
```

Открыть http://127.0.0.1:4179. Сервер отдаёт только эту папку, слушает только
loopback; с телефона по этому адресу не откроется. Сборка переносимого файла:

```powershell
node docs/prototypes/calm/build.cjs
```

## Что доведено

- Одна очевидная кнопка запуска; после неё Главная сохраняет композицию.
- Компактный плеер в отдельном слое, всегда зарезервировано место для прокрутки.
- Сохранение находки не переключает экран, не меняет станцию, не прерывает
  состояние воспроизведения. Краткое подтверждение и необязательный просмотр.
- Подбор открывается явно; веер показывает кандидатов. Только «Слушать» меняет
  станцию. Пользовательская пауза сохраняется при просмотре.
- Раскрытый плеер, пауза, повторное подключение, восстановление выбранной станции,
  отсутствие названия трека. Ни звук, ни metadata не измеряются этим макетом.
- Находки хранят источник и время; открываются поиском во внешнем сервисе.
  Сердце сохраняет отдельно станцию. Основной быстрый сервис в строке — Spotify.
- Поиск по четырём фикстурам, библиотека, доступные лотки с Escape, возвратом
  фокуса и fallback закрытия по подложке для Safari.
- Три темы, свой акцент и локальная картинка фона; «цвета из обложки» отдельно.
  Это собственная демонстрация токенов, НЕ интеграция с production Theme Studio.
- Небольшое движение обложки при сохранении; reduced-motion убирает его.

## Границы и честность

Это **макет без звука**. Станции/треки — демонстрационные пары, не текущий эфир.
Play меняет только локальное состояние с короткой имитацией подключения.
Рекомендации — фиксированный набор, не алгоритм сходства и не персонализация.
Жанры станции не используются для обещания сходства с конкретным треком.

Лира не подключена: у находки можно подготовить и скопировать вопрос, но ответ
не симулируется. На вкладке Глобуса только места демонстрационных станций,
полноценная карта не переносилась. Полные настройки аккаунта, очередь,
громкость, таймер и остальные действия плеера остаются в приложении.
Нет записи эфира, внешней синхронизации, аналитики или запросов к API.
Данные сохраняются отдельно под ключом localStorage `radioatlas-calm-v1`.
«Первый запуск» сбрасывает только станцию/состояние, сохраняет находки и тему.

## Проверено

Короткий Playwright CLI прогон, 27 утверждений основного сценария:
геометрия Главной до/после Play и сохранения, отсутствие самоперехода,
пауза при подборе, явное переключение станции, сохранение находки, внешняя
ссылка, восстановление без ложного playing, состояния ошибки/нет названия,
ширины 320/390/411, последняя строка над доком, размер управления ≥44 px.
Дополнительно: загрузка своего фона, переключатель цветов, фокус/пауза
раскрытого плеера, доступность действия лотка на 320×568.
Снимки визуально просмотрены в тёмной и светлой теме, включая подбор.

Локальные проверочные сценарии и PNG: `output/playwright/calm/` (gitignored).
Полный test/typecheck приложения не запускался: production TS/CSS/JS не меняли.
Настоящий iPhone, Safari и звук этим прогоном не проверены.

## Следующая точка

Посмотреть этот сценарий целиком и выбрать, что принимать в приложение.
Затем переносить один связный срез на существующие компоненты и состояния:
Главная → мини-плеер → поимка. Использовать реальные темы/Theme Studio и
модель находок. Полный плеер и подбор — следующими отдельными срезами.
Не возвращаться к полировке старых кнопок и не выдавать моковые рекомендации
или цветовые пресеты за работающий алгоритм/редактор.

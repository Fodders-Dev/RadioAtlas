## Что работает

- `npm run verify`: настоящие оба typecheck, API, bot, ops и webapp unit suites,
  без пропуска webapp units, который есть у исторического `npm test`.
- `--profile release`: добавляет offline Lira, build и serial functional lane.
  Платных вызовов/деплоя нет; `--dry-run` сохраняет только план.
- JSON/Markdown + отдельные UTF-8 логи, команды, ошибки, exit codes и длительности.
  Первая ошибка останавливает следующие шаги. Промежуточный RUNNING отчёт
  сохраняется до старта шага и после его завершения, поэтому прерванный процесс
  оставляет частичное свидетельство; оно не считается прохождением проверок.
- HEAD/branch/porcelain/diff hash/метаданные рабочих файлов до и после проверки.
  Изменившийся или неизвестный checkout даёт invalid и ненулевой код.
  Стабильное грязное дерево разрешено и явно описано; непроиндексированные файлы
  фиксируются по путям/size/mtime, не криптографически по содержимому.
- Уникальные папки по умолчанию; существующий отчёт нельзя молча перезаписать.
  Windows npm запускается через JS CLI с argv, без shell-интерполяции.
- CI fast job использует тот же runner и загружает ограниченную папку отчёта
  даже при сбое. Обязательные имена jobs и same-SHA deploy guard сохранены.
  Для `.tmp/verification-ci` включена загрузка hidden files: без этого
  [upload-artifact](https://github.com/actions/upload-artifact#uploading-hidden-files)
  по умолчанию исключает файлы внутри скрытой папки.
- [Карта реальных сценариев и стандарт ревью](DEVELOPMENT-QUALITY.md): уточнения
  Лиры, переход/сердце, плейлисты между устройствами, 200 избранных, очередь,
  iPhone resume. У каждого отдельно указана граница автоматического доказательства.
- Текущая передача сокращена с 1820 до 68 строк перед итоговой записью.
  Предыдущие 1820 строк целиком сохранены в архиве; main и Astra независимо
  сравнили сохранённый текст. Guard ограничивает активную передачу 120 строками
  и проверяет существование указанных test/spec файлов.
- Исправлены устаревшие e2e/CI инструкции и конфликт старой Sol-to-code схемы
  с более новым требованием владельца использовать GPT-6 Luna.

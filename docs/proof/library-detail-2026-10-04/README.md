# Плейлист — локальная production-сборка

Снимки сделаны Playwright CLI на `http://127.0.0.1:4194/?calm=1`.
Sol лично просмотрел результат и исправил найденные дефекты.
Подпись: **Реализовано, проверено**, композиция ещё не принята владельцем.

Изолированный профиль содержит тестовые станции Tokyo/Osaka/Kyoto/Sapporo/
Berlin/Hamburg/Munich, коллекции на 7/3/2 станции, три избранных и отдельную
очередь на четыре станции. Потоки `stream.example.com` не воспроизводятся:
снимки доказывают фактическую раскладку интерфейса, не слышимость радио.
Личные данные владельца не менялись. Пустой и одиночный плейлисты собраны
настоящими кнопками создания и добавления; это не дорисованные состояния.

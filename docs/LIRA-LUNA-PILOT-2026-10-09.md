# GPT-6 Luna: сравнение и личная проба

Статус: сравнение выполнено; личное включение ещё готовится. Владелец разрешил до **$3 суммарно на сравнение и пробу** и указал
свой Telegram-аккаунт для личной пробы. Это не разрешение переключить всех
слушателей или потратить весь баланс $5.

## Границы

- Действующая Лира использует `deepseek-v4-pro`, а не Flash: проверено по
  несекретной настройке production 09.10. Сравниваем именно эту модель.
- GPT-6 Luna включается только для одного числового Telegram ID, найденного
  по точному совпадению указанного владельцем имени в Telegram provider record.
  Публичный клиент не выбирает модель. Остальные пользователи и Mini App
  продолжают использовать прежнюю конфигурацию.
- Новый ключ хранится отдельно от глобального OpenAI/vision ключа; в исходники,
  отчёты и браузер не попадает. На RU authenticated model lookup возвращает
  `403 unsupported_country_region_territory`; на NL — 200. Узкий Responses
  transport использует существующий loopback/SSH путь, фиксированный HTTPS
  endpoint и ключ только в памяти relay.
- Tavily в личной пробе выключен: бюджет этого участка касается моделей.
  Это ограничивает проверку вопросов, требующих новых внешних источников.

## Расходы

Один отдельный smoke GPT-6 Luna завершён: 38 input / 20 output tokens,
оценка **$0.0000138**. Он подтвердил совместимость существующего Responses
адаптера, но не качество всей Лиры.

Остальной лимит разделён на сравнение **$1.00** и личную пробу **$1.99**.
Сумма со smoke меньше $3. Persistent SQLite ledger резервирует консервативный
верхний расход перед каждым сетевым вызовом; неизвестные сетевые исходы не
возвращают резерв. Перезапуск и deploy не обнуляют кампанию.

Резерв и оценка по usage — разные числа: резерв использует все UTF-8 байты
request как верхнюю границу text input tokens, запас на протокол, максимальный
output и не учитывает cache discount. Usage estimate не является счётом провайдера.

## Что считать доказательством

Одинаковые вопросы проходят настоящий Lira agent и одинаковый явно синтетический
каталог. Это сравнение модели/интерпретации/композиции ответа, а не проверка
доступности настоящих радиоэфиров. Бесплатные deterministic contracts учитываются
отдельно; ответы без модельного вызова не доказывают превосходство модели.
Ошибки модели и fallback не являются успешным модельным ответом.

Проверяются обычный русский разговор, энергичная музыка «как Sonic», уточнение
эпохи 2000–2014, Amiga/chiptune, отказ от предложенного и повторная подборка.
Сравнение не меняет согласованную композицию приложения.

## Результат

Первый парный прогон: 12 одинаковых сценариев на модель, по одному повтору,
настоящие запросы через существующий Lira agent и синтетический каталог.
Обеим моделям дан timeout 25s (обычный production timeout DeepSeek — 8s).
54 модельных вызова, по 27 на модель, без ошибок провайдера; usage получен
для каждого вызова. Бесплатные контракты: 24/24, отдельно от качества модели.

| Модель | Автоматическая проверка | Медиана полного ответа | Оценка usage по peak без кеша | Зарезервировано |
| --- | --- | ---: | ---: | ---: |
| DeepSeek V4 Pro | 12/12 | 3914ms | $0.10617552 | $0.759808 |
| GPT-6 Luna | 10/12 | 6855ms | $0.00878670 | $0.062721 |

Это исходные результаты, а не рейтинг полезности. У проверки «Нет, это совсем
не то» неверное ожидание: текущий продукт допускает новый набор в прежнем
направлении, поэтому новые карточки Luna сами по себе не ошибка. Фикстура
также не передавала предыдущие UUID и не проверяла свежесть набора.
Исходный отчёт не переписываем задним числом.

При уточнении «Не 90-е, а 2000 по 2014» Luna вернула пустую подборку, Pro —
станцию из синтетического набора. Парсер диапазона работает; первоначальный
отчёт не сохранял аргументы поиска, поэтому потеря контекста не доказана.
Адресный повтор с bounded synthetic trace прошёл без изменения runtime:
`query/tag=dance`, `language=Russian`, диапазон 2000–2014 вернули единственный
подходящий synthetic UUID. Два настоящих вызова, 5547 input / 379 output,
оценка $0.0007442, дополнительный резерв $0.005042, ответ 7804ms.
Первый промах не воспроизведён; причина остаётся открытой. Успешный повтор
не превращает исходный 10/12 в «исправленные 12/12».

Ручная оценка: Luna короче и яснее объяснила Amiga/chiptune; Pro назвал Amiga
«артистом». Но многие ответы обеих моделей одинаковы из-за шаблонов pipeline.
В сценарии исключения повторов обе модели получили структурный pass и
назвали чиптюн «поп-настроением» — проверка действия не доказывает релевантность.
Менять только модель недостаточно для интересной Лиры.

В этом небольшом прогоне Luna примерно в 12 раз дешевле по указанной оценке,
но медиана ответа в 1.75 раза больше. Это не доказательство общего превосходства
по качеству или скорости. Глобальная модель остаётся прежней.

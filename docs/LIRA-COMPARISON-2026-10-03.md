# Лира: сравнение двух источников, 03.10.2026

Реализовано и проверено локально. Новая композиция интерфейса не добавлялась.

## Что меняется для слушателя

После ответа с двумя карточками можно спросить «Чем эти две отличаются?».
Лира сравнивает именно последнюю пару, сохраняет её порядок и возвращает те же
карточки. Сравнение не запускает звук и не подменяет источники новым поиском.

Раньше поджанры исчезали: jazz / smooth jazz превращались в jazz / jazz,
deep house / tech house — в house / house. Теперь каждая строка сохраняет
поддерживаемые собственные поджанры станции, отдельно указана общая семья.

Пример на контролируемых данных через настоящий catalogue adapter:

> «Paris Jazz» (France) — jazz.
> «Tokyo Jazz» (Japan) — smooth jazz.
> Общие жанры каталога: jazz. Сравниваю формат по каталогу, а не музыку в эфире.

Это информация для выбора источника, а не обещание того, что сейчас звучит.
Общий house у одной карточки не означает, что там никогда не бывает deep house.
Неизвестные жанры и технические теги не доказывают музыкальные различия.

## Реализация и проверки

- `sourceComparison.ts` читает собственные private catalogue tags: максимум
  80, максимум шесть показанных жанровых меток в каждой строке. Поджанры
  сохраняются только из закрытого словаря; dnb / drum & bass, synthpop /
  synth pop и основные русские/английские алиасы не изображаются различиями.
- Полные собственные теги используются даже за публичным лимитом карточки.
  Публичные поля и общий `sourceGenres` не изменены. Имена и страны проходят
  существующий `sourceFacts`, произвольный текст тегов не используется.
- Последняя точная пара берётся из `lastSuggestedStationIds`. Старые карточки
  из `lastRecommendedStationIds` не восстанавливаются; отсутствующая карточка
  не заменяется чужой. Два `get_station`, без поиска и вызовов модели.
- Контроль старого кода из HEAD: assertion сохранения smooth jazz красный;
  те же два источника описаны как jazz / jazz. Новый offline контракт зелёный.
- Targeted tests: 18/18. Полный API: 862/862. Source/test typecheck и полный
  build завершились с кодом 0. Offline: 24/24, modelCalls 0; добавлены три
  сравнения. [Сырые результаты](evals/lira-comparison-2026-10-03-offline.json).
- Интеграционный тест использует `runLiraAgent` и настоящий adapter: две
  упорядоченные проверки карточек, completed/verifierPassed, zero model calls,
  action none/read, неизменный вход и публичные теги, очистка имени источника.
- Независимое Astra review не нашло блокирующих замечаний. Главный разработчик
  проверил diff и запуск тестов. Luna выполнила ограниченную реализацию.

## Ограничения и следующий шаг

Это проверка исполнения и каталожных фактов, не оценка качества живой модели.
Платных вызовов в этом участке нет. Физическое устройство, звук и отрисовка
экранов в этом API-участке отдельно не проверялись. Сравнение показывает
каталожный формат; оно не ранжирует станции по энергии, качеству или текущему
треку. Неподдерживаемый жанр может дать недостаток данных для сравнения.

Следующий участок — настоящий диалог подбора по свободной реакции с проверкой
действующих страны, числа и запретов. Новый платный прогон требует согласованного
бюджета; прежние журналы закрыты. Само сравнение не требует платного вызова.

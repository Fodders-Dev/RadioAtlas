# Лира: музыкальные вопросы как иллюстрированные карточки

01.10.2026. Ручное продолжение по просьбе владельца «думай шире, делай красоту».
Вариант для выбора: реализован локально, не принят и не опубликован.
База `a6f6bfe`, ветка `codex/calm-home`.

## Что изменилось для человека

Начальный экран calm больше не требует читать вступительный абзац и три
одинаковые большие карточки. Четыре иллюстрированных действия предлагают
конкретный музыкальный вопрос. Они используют уже существующий контекст:
выбранный источник, известный трек и время суток. Обложка, две пластинки,
рассвет/луна, волна и ритмические полосы нарисованы SVG в журнальной палитре.
Новых библиотек, загрузок картинок и генерации на открытии нет.

Рядом остаются настоящие источники каталога, их логотипы, страна/жанры, Play
и переход на Глобус. На телефоне это компактные строки под карточками; на
планшете/ПК — отдельная колонка. Старт заполняет доступную ширину до 960px,
после первого вопроса беседа сохраняет прежнюю ширину чтения до 740px.
Система вопросов и история остаются прежними: открытие не отправляет запрос,
кнопка отправляет только выбранный вопрос, готовая переписка не сбрасывается.

«Похожее за границей» содержит явное «не включай». Это не правило для всех
кнопок: существующий «Энергичный электро-микс» просит «Включи…» и допускает
явный запуск через ответ агента. Play в списке также является явным запуском.
SVG — оформление вопроса, а не обещание акустического анализа.

## Исправлено при проверке

- Изображение и подпись получили отдельные строки с 8px зазором. Убрано
  наложение волны на длинную подпись на телефоне и сжатие строки рисунка на ПК.
- Переопределено наследование заголовка: 26px на телефоне, до 32px на широком.
- Убрано внутреннее сжатие пустой grid-колонки до ширины её содержимого.
- Кнопка вопроса исчезает после отправки. При клавиатурном выборе фокус теперь
  переходит в оставшееся поле ввода, сохраняя черновик. Touch не открывает
  клавиатуру принудительно.
- ResizeObserver заново измеряет нижние controls при переходе между стартом
  и беседой: ошибка потока остаётся над composer, а не под ним.
- Нажатие карты/Play имеет область минимум 44px, есть видимый focus;
  декоративные SVG скрыты от accessibility tree. Hover отключён при reduced motion.

Luna реализовала ограниченный UI; Sol интегрировал и проверил. Независимое
ревью Astra обнаружило потерю фокуса и тесное соседство рисунка с текстом.
После исправлений повторное ревью исходников и свежих 390 light/dark,
834 PNG не нашло новых конкретных дефектов или перекрытия главных controls.
Ревью не является принятием дизайна владельцем.

## Проверки и доказательства

Оба typecheck, общий build и отдельная webapp-сборка с `VITE_AI_ENABLED=1`
прошли с exit 0. Лира в production opt-in; обычный build без этого флага
правильно скрывает её. 899 webapp unit tests прошли на окончательном runtime.
Полный functional на окончательном runtime: **434 passed, 7 skipped,
5 failed, exit 1**. Пять отказов были в подготовке нового studio-теста:
он ожидал подключённый src у ещё не запущенной восстановленной станции.
Теперь тест явно запускает её кнопкой Feed, ждёт playing/src/Mock Song,
на 834 ставит на паузу и только затем снимает snapshot. Первая поправка
ожидала скрытый в Feed мини-плеер; ожидание перенесено в видимый transport
Feed. Следующий адресный запуск остановлен после выявления ожидания
иностранного вопроса, которого может не быть в текущей ротации при известном
треке. Studio-тест теперь выбирает видимый вопрос о станции; точный
иностранный запрос отдельно проверяет существующий source-entry spec.
Ни один runtime/assertion сохранения src/paused/queue не ослаблен.
**Окончательный адресный повтор: 12/12, exit 0** (studio, calm-lira,
source-entry); финальный webapp test typecheck — exit 0. После полного
прогона менялась только подготовка/выбор вопроса в новом тесте и документация;
общий 13-минутный прогон не повторялся. Это совокупное покрытие, а не заявление
о зелёном exit code последнего полного запуска.

Новые сценарии на 320×740, 390×844, 834×1112, 1024×768, 1440×900 проверяют
точный UUID, ноль запросов при открытии, один явный вопрос о станции,
сохранение src/paused/queue, черновика и keyboard focus, возврат к беседе,
области нажатия, отсутствие горизонтального overflow и зазор art/caption.
Два сценария Aurora Field проверяют тёмные подписи и reduced motion.
Существующие проверки Home/Feed/Globe, клавиатуры и ошибок плеера сохранены.

В браузере дополнительно просмотрены текущий Vite UI и собранный bundle
на локальном fixture-сервере на всех пяти размерах; на 320 прокрутка доводит

Явный иностранный вопрос прошёл через настоящий
agent/catalogue adapter и вернул Paris/Tokyo по Berlin. Поток намеренно 404:
эта проверка подтверждает UI/контекст, не слышимость радио. Для сохранённой
беседы через Theme Studio создан и применён контрастный локальный remix;
старт на пользовательском bitmap-фоне этим проходом не проверен.

Пять перспектив: новичок видит конкретные действия до набора текста;
постоянный слушатель сохраняет источник/очередь и беседу; композиция использует
ширину без растянутого чата; accessibility — кнопки/focus/reduced motion;
условия — узкий экран, планшет, ПК, светлый/тёмный фон, существующий длинный
контекст и shrinking keyboard spec. Две волны «работа/lofi» остаются близкими
по рисунку — ограничение визуального разнообразия для следующего просмотра.

## Следующий шаг и ограничения

Показать этот локальный вариант владельцу перед подготовкой выпуска этапа 6.
Качество свободной модели, реальные аудиопотоки, физические iPhone/Android и
наушники не проверялись. Платных provider/eval/artwork calls нет. Ночной
heartbeat остаётся приостановлен. Все вопросы/станции доступны прежними
инструментами; акустическая похожесть и персонализация по находкам не обещаны.

# Станция из Ленты в плейлист — 28.09.2026

Статус: реализация Luna, независимый UI-проход Astra и локальные проверки завершены; публикация впереди.
База: `fded6ce`, runtime в проде `1100d0f`.

## Сценарий

Понравилась станция → «Ещё» → «В плейлист» → выбрать существующий либо
создать новый → продолжить слушать ту же Ленту. Сохраняется станция открытой
карточки, которая может отличаться от играющей. Само сохранение не запускает
радио, не меняет очередь, её источник, позицию или видимую карточку.

В активной Calm-ветке `StationFeed.handleOpenPlayer` открывает
`FeedPlayerTools`. Новый вход добавляется туда, а не на основную панель Ленты.
Выбор плейлиста переиспользуется из существующего `StationPlaylistDialog`
в `StationTable`; отдельная модель плейлистов не создаётся.

## Проверка перед выпуском

- Существующий и новый плейлист, пустое/пробельное имя, повторное добавление.
- Отмена, Escape только верхнего окна, возврат фокуса, открытие после отмены.
- Сохранение неиграющей карточки при звучащей другой станции; неизменный
  реальный audio source и состояние паузы, непустая очередь и её порядок.
- Сохранённое переживает reload; прежний вход из StationTable продолжает работать.
- Личный набор → порядок → запуск в Ленте → перемешивание хвоста с сохранением текущей.
- Материалы и читаемость в светлой/тёмной теме, 320/390/834/1440, длинные
  имена/списки, прокрутка и ввод названия. Цели не меньше 44 px.
- Оба typecheck, webapp unit, целевые проверки, production build, полный
  functional после фиксации исходников; реальный UI и проверка опубликованной версии.

Наблюдение до реализации: у действия addStationToCollection предел 128, после
добавления хвост обрезается. Новый выбор не должен незаметно вытеснять уже
сохранённую станцию из заполненного набора. Это проверяется отдельно.

Итоговые результаты, найденные недостатки и факт публикации записываются
после проверки; этот документ пока не является отчётом о готовности.

## Первый независимый проход

Astra открыла реальную Noise FM из Ленты на 390×844, создала «На ходу ·
проверка Ленты 28 сентября». Повторное открытие правильно показывает «Уже
добавлена», Escape закрывает только выбор плейлиста и возвращает фокус
на «В плейлист» в меню. Пауза сохранилась. Проверены Classic и светлая
пользовательская тема «Проверка 3D Remix — сохранено».

Возвращены Luna на доработку до полного прогона:
1. Успех оставлял меню открытым, хотя должен вернуть к слушанию Ленты.
2. Основная кнопка унаследовала старый `.chip`: шрифт 10px и сине-серый
   материал в тёплой теме. Нужна читаемая кнопка действия в текущей палитре.
3. Статус «Уже добавлена» чрезмерно бледный из-за opacity всей строки.

Это промежуточные наблюдения, не приёмка итогового интерфейса.

## Повторный независимый проход

Три замечания выше исправлены. При добавлении в существующий набор и создании
нового на реальном потоке Noise FM меню закрываются, фокус возвращается в Ленту,
`audio.currentSrc` неизменен, `paused=false`, время потока продолжает идти.
После проверки эфир явно поставлен на паузу. Сохранённые наборы пережили reload.

Просмотрены 320×640, 390×844, 834×1112 и 1440×900; Classic и светлая
пользовательская тема. Кнопка создания 16px, формы и длинные названия читаемы.
На 390×480 найден четвёртый дефект: CSS grid сжимал строки списка, подпись
наезжала на следующую строку. Исправлено intrinsic-размером строк. Повторный
замер: строки 71/93/71px, подпись внутри каждой с нижним запасом 10px.
Список прокручивается; форма доступна прокруткой и Tab, кнопка заканчивается
на 464px при высоте окна 480px. Физическая экранная клавиатура не проверялась.

Доказательства в `output/feed-playlist-phone.png`, `feed-playlist-desktop.png`,
`feed-playlist-short-before.png` (дефект), `feed-playlist-short-after.png`.
Заполненные наборы (128 станций) и дубликаты недоступны для добавления;
сохранённый хвост не вытесняется. Это ограничение существующей модели данных.

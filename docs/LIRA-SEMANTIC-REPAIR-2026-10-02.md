# Лира: свободная просьба и короткое «и?» — 02.10.2026

Серверный участок реализован и проверен, **в production пока не опубликован**.
RU-сервер `77.91.113.109` не отвечает по SSH/HTTPS с этой машины и NL;
внешний uptime job GitHub тоже зафиксировал тайм-аут. Локальные изменения
не установлены на RU и не являются причиной этого наблюдаемого отказа.
Следующий шаг — восстановить доступ к RU, выпустить этот серверный участок
через штатные same-SHA CI gates и проверить публичный диалог.
Непросмотренный Lira Studio в этот выпуск не входит.

## Что изменилось для слушателя

- «Хочется скоростного как Sonic» больше не отсекается как обычная болтовня.
  Существующий planner классифицирует свободную просьбу, выбирает жанровый
  поиск и возвращает проверенные станции. Дополнительного classifier call нет.
- «И?» / «где варианты?» продолжают исходную пользовательскую просьбу и её
  уточнения. Страна применяется до поиска, количество и исключения сохраняются.
  Прежнее «включи» не разрешает новый play по короткому уточнению.
- Немуззыкальное желание, даже со словом «вечером», не должно запускать
  вечернее радио. Новая ветка требует допустимого planner intent; `chat`,
  `knowledge`, `clarify` и некорректная классификация не обходят gate через backstop.
  Старые явные жанровые ветки сохраняют прежнюю страховку.
- Ответ не заканчивается собственным «сейчас гляну/подберу» без продолжения.
  Пустая семантическая рекомендация показывает реальные сервисные ссылки либо
  честное отсутствие найденных вариантов. Fallback больше не изображает амнезию.
- Раннее завершение поиска учитывает исключения и уже показанные UUID.
  Карточка с запрещённым тегом не считается готовым результатом.
- Частые абсолютные обещания отсутствия рекламы/ведущих/вокала/новостей
  заменяются реальными каталожными фактами с оговоркой о живой программе.
  Это узкая эвристика, **не полный семантический валидатор**.

## Настоящий прогон: бюджет и сравнение

Владелец разрешил отдельный лимит **до $3** для воспроизведения этой переписки.
20 реплик, 41 DeepSeek Pro call, web calls 0. Верхняя оценка **$0.12459744**,
неопределённого резерва нет. Ledger закрыт; остаток не разрешает новую кампанию.
Расчёт по [официальному peak тарифу](https://api-docs.deepseek.com/quick_start/pricing/)
$1.32/$3.96 за миллион input/output tokens, без скидок кеша/off-peak; это не счёт.

Из-за недоступности RU прогон выполнялся на здоровом NL сервере:
bundled brain + настоящий `deepseek-v4-pro`, ключи остались на VPS.
Каталог получался через существующие loopback HTTP routes NL. Файлы snapshot
и `.env` инструментами не читались и не копировались. Каталог — тот, который
отдаёт HTTP API NL; совпадение профильных overrides с RU не проверялось.
Для разрешения стран adapter мог
прочитать до пяти страниц по 100 строк; это ограниченный срез, не полный scan.
8 секунд на model call и 18 секунд на agent turn сохранены.
Каждый batch предварялся 21 fixture-only contract, 0 model calls.
Результаты этого preflight не являются оценкой качества настоящей модели.

| Проверка | До | После последней правки |
| --- | --- | --- |
| Sonic → «и?» | 0 → 0 карточек, встречные вопросы | 5 → 5 проверенных карточек |
| «несусь по неоновой трассе» → «и?» | отдельного baseline нет | 5 → 5 карточек в повторе до последнего prose guard |
| «вечером пиццы» → «и?» | отдельного baseline нет | 0 → 0, поиска станций нет |
| Россия, без новостей, один вариант, NoPlay → «и?» | отдельного baseline нет | 1 → 1, обе из РФ, действия только `open-station` |

Сохранён и неудачный промежуточный повтор: первый поиск дал карточки, но «и?»
вернул неподтверждённые DnB Radio/JungleTrain без tools/cards. После него
planner стал получать восстановленную USER-просьбу как текущую задачу;
composer и авторизация действий продолжают получать исходное текущее «и?».
Завершающий повтор также проверил замену ложного «без новостных вставок».
Действия из ответов не исполнялись, звучание станций не проверялось.

В завершающих повторах рекомендации заняли **5.1–13.4 секунды**; раньше в
этой же кампании некоторые ответы укладывались в 3.4–5.8 секунды. Тайм-аутов
провайдера в сохранённых reports нет. Это улучшение завершённости задачи,
а не доказательство мгновенного ответа или стабильной скорости на RU.

733 API tests, 151 focused tests, оба полных typecheck, API build и 21 offline
contract прошли по exit code. Независимое Astra review обнаружило и помогло
закрыть обходы chat/strict gate, ошибочную отмену NoPlay, преждевременный stop

UI не менялся; браузерный диалог, физический телефон и российский provider
path в этом участке **не проверены**. Не запускать непоказанный Studio ради
проверки этого backend fix.

Лира ещё ошибается в музыкальных пояснениях: в одном повторе приписала жанры
третьей карточки «второй»; встречалась фраза «врубаем» при правильном NoPlay
action. У UUID-дедупа остаются зеркала одной станции с разными UUID; в одном
повторе такая станция встретилась снова. Жанровое ранжирование по широким
каталожным тегам не доказывает скорость/инструменты звучащего трека.
Эти примеры не скрыты в reports и не закрываются текущими эвристиками.

После восстановления RU и этого выпуска следующий отдельный участок:
grounded пояснения, связанные с конкретными карточками, и устранение зеркал
при коротких повторных рекомендациях. Для нового платного прогона нужен
новый бюджет; текущая кампания закрыта.

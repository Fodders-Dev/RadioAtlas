# Лира: выбранный источник во всех входах

01.10.2026. Следующий клиентский участок этапа 5 реализован локально.
Продолжает серверный участок `68eec09`; новой композиции экранов не вводит.
Публикации и платных provider/eval calls в этом проходе нет.

## Поведение

- «Спросить Лиру» в drawer Главной и «Лира» у выбранного источника Глобуса
  открывают чат с целым StationLite и UUID, без автоматического вопроса.
  Лента сохраняет уже существовавший такой вход.
- Над перепиской закреплены artwork и имя выбранного источника. Контекст
  виден и при сохранённой беседе, длинное имя сокращается с полным title.
  Это информационная строка, а не второй плеер.
- «Похожее за границей» отправляет явный запрос по выбранному UUID только
  после нажатия. Имя станции не подставляется в этот запрос вместо UUID.
  Сервер разрешает факты по каталогу и возвращает родственные жанры другой
  страны; это не обещание акустической похожести или здоровья потока.
- Если в плеере другая станция, её трек не уходит как трек выбранного
  источника. Открытие, предложение и возвращение сохраняют transport и очередь.
- «Очистить чат» на широком экране — центрированная иконка в круге 44px,
  с accessible name/title. Подпись не переносится за границу круга.
  Клавиатурное подтверждение и отмена остаются прежними.

## Проверки

Source typecheck, test typecheck, webapp build и 899 unit tests — exit 0.
Первый полный functional: **431 passed, 7 skipped, 1 failed, exit 1**.
Старый Home discovery spec не дошёл до проверки размеров: не появился anchor
`data-home-feed-entry` за 15 секунд. Неизменённый тест в предписанном
`--repeat-each=12 --workers=6` прошёл 12/12, exit 0. Причина единичного отказа
не установлена; assertions, timeout и runtime не менялись. Лог отказа сохранён.
Последний общий functional на финальном runtime: **432 passed, 7 skipped,
0 failed, exit 0**. После этого только усилено ожидание в новом Home spec:
перед переходом явно проверяется полученный трек Mock Song в мини-плеере,
чтобы отсутствие чужого трека в запросе не было следствием гонки metadata.
Повтор усиленного адресного spec: **3/3, exit 0**; финальный test typecheck:
**exit 0**. Полный runtime-прогон не повторялся после одного ожидания в тесте.

Адресные 18 сценариев прошли за два запуска: существующие Feed/Globe 15,
затем три новых Home после исправления ожидания persisted queue в тесте.
Первоначально Home snapshot снимался до пакетной записи новой очереди на диск
и сравнивал старую seed-очередь с актуальным runtime. Теперь сначала ожидается
именно список видимых эфиров Главной; runtime и assertions не ослаблялись.

Новый Home spec на 390×844, 834×1112 и 1440×900 проверяет другую играющую
станцию (на tablet — паузу), сохранённую беседу, длинное имя, ноль запросов
при открытии, ровно один явный запрос с нужным UUID без чужого трека,
неизменные src/paused/queue, возврат и повторный вход с новым источником.
Clear проверяется по геометрии, Enter и отмене native confirm.
Globe spec проверяет ноль запросов при открытии и точный UUID после явного
вопроса; возвращение сохраняет выбранный источник и приближение карты.
